V39.2.3 — توقع البطل داخل سجل توقعاتي

تغييرات واجهة المشارك:
- إضافة توقع بطل كأس العالم كسجل مستقل داخل توقعاتي.
- يظهر السجل زمنياً بين ربع النهائي ونصف النهائي.
- يعرض المنتخب المختار وعلمه، حالة الاختيار، والرصيد بطريقة واضحة.
- لا يظهر الرقم 0 لتوقع البطل؛ تظهر بدلاً منه عبارات مثل:
  - بانتظار الحسم
  - بدون نقاط
  - لم يُسجّل
- بعد اكتمال النهائي فقط، تظهر بطاقة ختامية أعلى صفحة توقعاتي تلخص نتيجة توقع البطل.
- البطاقة تفرق بين: بطل صحيح، وصيف، اختيار لم يصل، أو عدم تسجيل توقع.
- تحسين كامل للجوال مع جدول من ثلاثة أعمدة قابل للقراءة دون تمرير أفقي.

هذه الحزمة تركز على واجهة المشارك كما طُلب. إعادة تصميم الإدارة ستنفذ كمرحلة مستقلة حتى لا تؤثر على تجربة المشاركين الحالية.
